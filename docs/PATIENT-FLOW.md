# 患者核心流程

1. 打开工作台，选择合成档案 A（新近确诊、少量记录）或 B（长期随访、多次发作）；可新建本地档案。
2. 选择“记录发作”或“新增资料”。输入日期/时间、原始观察、可选体温/部位/影响、来源；症状不是诊断标签。
3. 保存后查看档案时间线；修正通过新增更正/停用旧记录完成，保留来源。错误时保留草稿并允许重试。
4. 复诊前查看时间轴与检验趋势，复制/导出患者自己选择的摘要；隐私记录默认不进入分享或 AI 上下文。
5. 可浏览公开研究快照；页面始终显示登记来源、访问/快照日期及通道是否失败。收藏仅表示关注。

治疗选择、发作危险性或“是否入组”等判断出口固定为“请把这条信息带给你的医生讨论”。
