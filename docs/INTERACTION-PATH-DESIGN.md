# M2 交互路径与 CRUD 双通道

原型：`prototypes/v0.2/index.html`。模拟数据只有两套合成档案；所有写入在 `file://` 演示模式仅暂存在内存，刷新重置。业务组件路径 `/api/traps` 在 M5 接通。

| 场景 | 路径：入口 → 步骤 → 产物 → 返回 | 手工通道 | AI 协助通道 | 删除/更正 |
|---|---|---|---|---|
| S1 记录发作 | 概览「记录」→ 选择症状/发作 → 日期、原始观察、持续时间、来源/私密 → 保存 → 当前档案时间线 | 默认且无需 AI；可只填标题/日期 | 用户主动开右侧原生会话、逐项选择可带入内容；私密默认排除 | 更正通过新记录及来源说明；软停用，保留历史 |
| S2 复诊准备 | 概览问题清单/资料 → 选择记录 → 预览 → 导出本地 HTML → 回概览 | 全流程手工完成 | AI 只能整理选中的已记录内容，不补事实 | 移除导出选择不删档案事实；档案更正保留原来源 |
| S3 检验回顾 | 记录 → 检验 → 原始数值/单位/参考范围/日期/机构/来源 → 指标卡或一图秀 | 表单输入、无单位时不强制推测 | AI 可协助转录但目前未接入报告解析 | 更正不覆盖原件；停用旧值并重新录入 |
| S4 浏览研究 | 研究 → 关键词/登记号/地区 → 详情与原始登记链接 → 收藏/回顾 | 可不建档案字段、不需 AI | 用户显式询问时只生成待问问题，不判资格 | 取消关注只移除本机收藏，不更改登记快照 |
| S5 管理隐私与来源 | 设置 → 资料目录/数据来源/隐私 → 查看真实状态 | 可取消目录选择、重试 | 不自动上传，不自动带入 | 切换目录不搬迁/删除；隐私标记可撤销 |

取消或失败保留表单内容；0 条和通道失败使用不同状态。下一步：M5 对照生产服务合同验收取消、写后回显和旧档案兼容。
