# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：TRAPS 患者本人与家长/照护者双主体（儿童期起病为主，家长代记常见）；覆盖确诊（TNFRSF1A 基因检测由医生确认）、发热发作（起止/持续天数/伴随症状）、发作期与间期治疗、CRP/SAA 炎症指标随访、就医提示全程

场景：患者/家长整理每次发热发作的起止与持续天数、伴随症状（皮疹/肌痛/眶周水肿/腹痛/关节痛）、发作间期与发作期的用药剂量、CRP/SAA/血沉复查值与化验报告，追踪发作规律，准备复诊问题并回顾医生确认后的记录

核心流程：
1. 选择本地资料目录并登记化验（CRP/SAA/血沉/血象）、报告与用药材料
2. 记录发热发作（起止、持续天数、伴随症状）并回顾发作规律时间轴
3. 整理发作期与间期治疗方案与剂量变化，回顾治疗响应
4. 核对炎症指标趋势与医生确认结论，形成家庭可读的随访时间轴
5. 准备复诊问题清单并记录医生答复，管理私密内容

完成结果：患者/家长能看到按类别分组的炎症指标随访时间轴、发热发作记录与持续天数统计、治疗剂量折叠卡，能新建自己的真实档案（与演示档案隔离）并回看医生确认后的记录，就诊前能导出带来源的病情摘要
