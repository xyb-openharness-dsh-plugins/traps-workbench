# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：TRAPS 患者与照护者；医生审核仅为后续待验证环节

场景：记录周期性发作与日常症状，汇总可追溯的检验和就诊资料，并查看公开临床研究信息

核心流程：
1. 选择或创建本地合成档案，查看发作与记录概览
2. 记录一次发作、症状、检验或就诊事件并标注来源
3. 回顾时间轴和公开研究条目，整理可带去咨询医生的问题

完成结果：新增记录可追溯到来源并显示在档案时间轴；公开研究条目显示登记来源和访问日期；任何治疗选择问题均引导咨询医生

初始布局选择：business-first
