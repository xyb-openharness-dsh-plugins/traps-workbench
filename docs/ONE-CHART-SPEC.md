# TRAPS 指标与发作时间轴

状态：M2 交互原型合同；样例值为合成数据，不能用于医学解释。M3–M5 开发复核。

| 维度 | 本项目口径 |
|---|---|
| 一期指标 | CRP、ESR、SAA、体温观察及用户自定义项目；没有数据则为空态 |
| 类别 | 炎症指标 / 发作观察 / 其他；与指标卡组顺序来自同一 read model |
| 可比性 | 同指标、同单位、同方法才进入同组；参考范围保留原报告/合成数据来源，不跨机构臆造统一阈值 |
| 归一化 | 每条线按该指标全期 min/max 单独归一化；展示“曲线不可互相比高低” |
| 单点/空窗口 | 单点只画点不连线；无值显示空态，不构造零值 |
| 事件层 | 发作/就诊/检验事件与指标层分开显示；不将事件当成因果 |
| 治疗条 | 仅记录用户输入的既定医嘱时间，不推荐、不将其画成疗效解释 |
| 来源 | 指标详情保留采样日、单位、机构、方法、来源；生成的展示不覆盖原始事实 |

当前原型把 4 类量纲差异大的指标独立归一化；没有做临床正常/异常分级。扩展时间窗、点选来源、减少动效及窄屏检查在 M5/M9 核对。
