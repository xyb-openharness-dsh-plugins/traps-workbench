# 与 MPN 参考实现的差异矩阵

| 能力 | 参考实现借鉴 | TRAPS 适配 | 不带入 |
|---|---|---|---|
| 多档案、来源可追溯记录 | 本地 SQLite、私密过滤、写后统一 bootstrap | 发作、症状、就诊、遗传报告、实验室指标 | MPN 血象指标、脾脏/血栓专属语义 |
| 指标卡与时间轴 | 可比组、原始单位、日期、治疗/事件分层 | CRP/ESR/SAA等只在有来源记录时呈现；不设默认临床阈值 | MPN 分级/预后和实体瘤分期 |
| 临床研究 | 快照、来源状态、筛选、收藏与解释 | 仅保留核实为 TRAPS/自炎症自然史的公开登记记录 | MPN 试验与跨病种误判为 TRAPS 的记录 |
| 疾病概要 | 四段结构、原件标注、解释层 | TRAPS定义、资料规范、已发生监管/研究事实 | 预后承诺与治疗选择建议 |
| 会话/工作区 | DSH公开会话归属接口与本机数据边界 | 保留本地优先、按需 Agent 右侧面板契约 | 自建聊天、自动上传患者档案 |
