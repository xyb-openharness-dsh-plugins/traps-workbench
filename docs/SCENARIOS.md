# 场景与优先级（M1 草案）

状态：依据现有桌面证据形成的产品假设；未经真实患者共创。每条可在访谈后改写。

| 优先级 | 触发 → 动作 → 产物 | 证据与边界 |
|---|---|---|
| S1 发作记录 | 发作开始/变化/缓解 → 记日期、体温、疼痛/皮疹/眼部或腹胸部表现、影响与来源 → 可供复诊回顾的时间线 | E1/E3；功能高价值假设，不能判断发作性质 |
| S2 复诊资料整理 | 复诊前或跨机构就医 → 汇集发作、检验、遗传报告摘要及待问问题 → 本地可导出的复诊摘要 | E1/E2；不生成诊断或建议 |
| S3 检验回顾 | 新检验单 → 录入日期/原始值/单位/参考范围/实验室 → 同指标趋势视图 | E1/E2；无参考区间则不分级、不比较 |
| S4 公开研究浏览 | 患者主动查看 → 关键词/疾病/地区筛选登记记录 → 保存来源链接与讨论问题 | E5；结果仅供讨论，不判断个人入组资格 |
| S5 家庭与遗传资料边界 | 录入遗传结果或家族史 → 标记来源、确认状态与私密性 → 私密档案事实 | E1；必须区分致病/可能致病/VUS/未检出/未检测；不解释家族风险 |

一期：S1–S4；S5 仅支持来源和私密标记，不做家系推断。停止/错误恢复：写入前可取消；保存错误保留草稿；来源未知明确显示“未提供”；移除采用软删除/更正而非静默清除。
