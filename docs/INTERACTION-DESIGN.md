# 交互设计与功能边界

- 主布局：业务整页 `customFrame`，宿主原生 Agent 按需出现在右侧；不启动时业务区仍完整可用。
- 首页优先显示当前档案、最近记录、发作时间线入口和“记录发作”；右上角具名设置、疾病概要入口。
- 记录闭环：入口 → 最少输入 → 来源/隐私 → 保存反馈 → 时间线回顾/更正。
- 两套合成档案贯穿整页切换，档案选择不串写。患者新建空档案时显示空状态 CTA。
- 失败/无数据：来源失败与 0 条结果分开；未检测与阴性分开；缺单位时不强行比较；加载错误提供重试。
- Agent 带入材料由用户明确选择；敏感/私密记录不默认带入；用户保有草稿与发送控制。
- 视觉方向：轻量医疗记录工具，不以疾病品牌或装饰遮盖数据；“TRAPS 工作台”为占位名，待用户追认。
