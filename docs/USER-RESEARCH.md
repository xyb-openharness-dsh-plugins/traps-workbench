## 初步任务假设（需要患者访谈验证）

1. 发作开始/结束时间、体温、部位与症状变化分散在记忆和多次就诊中；希望快速记录并生成可分享的时间线。依据 E1、E3；推断而非已验证需求。
2. 发作与缓解期间的检验结果、单位、参考范围和采样日期需要并排回顾；不能将不同机构/方法的结果自动等同。医学约束来自 E1/E2，用户价值尚未访谈验证。
3. 罕见病患者可能跨机构求诊，复诊时需要保存报告来源、遗传报告原文和待问问题；遗传资料可能涉及家庭隐私，默认私密。
4. 公开研究入口便于患者和医生讨论，但“匹配分”只表示字段重合，不构成资格、招募状态或治疗建议。

## 缺口

- 患者和照护者访谈：0；中国大陆/中文语境患者组织与实际流程尚未验证。
- 临床审核：0；GeneReviews 与 EULAR/ACR 原件可访问，但未有临床审阅者签认。
- 指南本地适用性、药品监管信息、患者报告结局工具的授权与中文版本：待研究。
